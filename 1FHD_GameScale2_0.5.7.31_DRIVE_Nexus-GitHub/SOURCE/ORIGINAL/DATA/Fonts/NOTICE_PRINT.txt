The derived AFT family is named FHD Print Bold. It contains native game metrics
and a slight expansion of already-bold outlines for small interface text.
The source is in SOURCE/Fonts/DejaVuSans-Bold.ttf.
Rebuild: python3 SOURCE/build_print_font.py (Pillow + fonttools required).
Playing requires neither Python nor an installed system font.
