XenoStable Runtime 1.5.1

Нативный модуль для XenoNativeLoader. Он переносит исправления встроенного
Rangers Stable 1.4.12 в память процесса, не изменяя Rangers.exe на диске:

- достижения при активных модах;
- D3D9On12 с сохранением Steam Overlay;
- восстановление текстур после Alt-Tab;
- borderless fullscreen;
- отсутствие повторного захвата фокуса;
- нормальный Z-порядок игры и её окон ошибок в фоне.
- скрытие застывшего кадра игры, если оконный поток занят долгим расчётом;
- кнопка игры на панели задач, даже если во время загрузки выбрано другое окно.

1.5.1 исправляет запуск, во время которого игрок переключился на другую
программу. Игра включает видимость окна через стиль, а не через ShowWindow,
поэтому Windows создавала кнопку на панели задач только при активации окна.
Без активации игра работала, но оставалась без кнопки и позади других окон.
Теперь XenoStable регистрирует кнопку сам, как только окно стало видимым;
фокус у выбранного приложения при этом не отбирается. Отключается через
TaskbarButtonFix=0.

1.5.0 ищет каждое исправление кода отдельно и поддерживает prerelease-сборки
2026-10 (Space Rangers Universe). Если для незнакомой сборки не найдено место
одного исправления, отключается только оно; строка stable_features= в
XenoNative.log показывает итоговый набор.

1.4.11 автоматически оставляет штатный D3D9 для оконного разрешения меньше
рабочего стола, поэтому Full HD окно на 2K-мониторе не получает белый backbuffer.
Для нативного разрешения монитора D3D9On12 и Steam Overlay сохраняются.

Модуль ждёт две секунды стабильной геометрии после смены разрешения и не
растягивает окно с разрешением меньше рабочего стола. Это не даёт borderless
вмешаться в пересоздание D3D backbuffer при переключении 2K/Full HD.

Модуль подтверждает уход в фон свежим пользовательским вводом и геометрическим
пересечением окон, не доверяя Z-порядку зависшей D3D-поверхности. По умолчанию
застывший кадр скрывается после 750 мс занятости оконного потока. При Alt+Tab или
Win+Tab cloaked-кадр заранее открывается на короткое время, чтобы окно не
застряло вне переключателя задач; после выбора игры оно восстанавливается
обычным путём. Задержки можно настроить через BusyFrameCloakDelayMs и
SwitchRestoreGraceMs в XenoStable.ini. Системная смена foreground без ввода
по-прежнему не вызывает скрытие. При зависшем игровом потоке Stable не пытается
повторно отбирать foreground у активного приложения: это предотвращает краткий
скачок курсора в игру и обратный возврат мыши.

Настройки находятся в XenoStable.ini рядом с DLL. Чтобы временно отключить
модуль, установить Enabled=0 либо переименовать его XenoNativePlugin.ini.
